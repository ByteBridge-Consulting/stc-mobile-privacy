# Intercity STC — Privacy Policy

Public privacy policy for the **Intercity STC** mobile app, hosted on GitHub Pages
so it can be linked from the Google Play Console and the App Store.

**Live URL:** https://bytebridge-consulting.github.io/stc-mobile-privacy/

The policy is a single self-contained `index.html` — no build step, no dependencies.
Edit it and push to `main`; Pages redeploys automatically.

## Before this is submitted to Play

`index.html` section 10 contains **placeholders** that must be replaced with STC's
real privacy contact email, postal address, and phone number. Google Play requires a
working contact route.
